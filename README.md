# Misoto22/homebrew-tap

Homebrew casks for Misoto22's macOS apps.

```bash
brew install --cask misoto22/tap/jade
```

| Cask | App |
|---|---|
| `jade` | [Jade](https://github.com/Misoto22/jade) — break reminder with a resident desktop cat |

Each cask is written by the app's own release workflow, as the `misoto22-release-bot` App, when a release is published. Edit the template in the app's repository (`packaging/homebrew/`), not the file here.
